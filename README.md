# Виджет банковских операций клиента
Страница "Главная" банковского приложения, простой пользовательский поиск и отчёт трат по категориям
## Установка
Клонируйте репозиторий:
```
git clone https://github.com/username/project-x.git
```
Установите зависимости, используя менеджер пакетов 'poetry':
```
poetry install
```
## Использование:

Откройте виджет в вашем PyCharm.
Виджет включает в себя следующие функции:
1. Модуль utils.py содержит функции:

load_user_settings--Загружает пользовательские настройки из файла user_settings.json

greeting--Приветствие в зависимости от текущего времени

read_excel--Чтение из excel файла

get_operations_with_range--Вывод операций в заданном временном промежутке
    Данные для анализа и вывода на веб-страницах — это данные с начала месяца, на который выпадает входящая дата,
    по входящую дату.

get_cards--Выдаёт по каждой карте:
    последние 4 цифры карты;
    общая сумма расходов;
    кешбэк (1 рубль на каждые 100 рублей).

get_top_transactions--Выводит Топ-5 транзакций по сумме платежа.

get_currency_rates--Возвращает актуальные курсы валют

get_stock_prices--Возвращает актуальные курсы акций

2. Модуль views.py содержит функцию:

main_page--Собирает в себе набор функций (greeting, read_excel, get_operations_with_range, get_cards, get_top_transactions,
    get_currency_rates, get_stock_prices) в главной функции, принимающей на вход строку
    с датой и временем в формате YYYY-MM-DD HH:MM:SS и возвращающую JSON-ответ со следующими данными:
    из функций

3. Модуль services.py содержит функцию:

simple_search--Пользователь передает строку для поиска, возвращается JSON-ответ со всеми транзакциями,
    содержащими запрос в описании или категории.

4. Модуль reports.py содержит функцию:

spending_by_category--Функция возвращает траты по заданной категории за последние три месяца (от переданной даты)

## Тестирование
Код покрыт тестами. Для ознакомления зайдите в htmlcov -> index.html и оттуда перейдите в браузер -
вы увидете процент покрытия кода тестами. Также это можно сделать командой
```
poetry run pytest --cov
```
Все тесты расположены в пакете tests.
